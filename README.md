# qlmao.github.io

Personal academic homepage of **Qinglin Mao (毛庆霖)** — hosted with GitHub Pages.

- English: https://qlmao.github.io
- 中文: https://qlmao.github.io/index-zh.html

## Structure

```
index.html            # English page
index-zh.html         # 中文页面
assets/css/style.css  # stylesheet
```

Static HTML/CSS only — no build step, no external dependencies. The "Download CV" button links to the
[CV repository](https://github.com/QLMao/CV).

## Editing

Content lives directly in the two HTML files (English in `index.html`, Chinese in `index-zh.html`).
Keep the two in sync when updating. Styles are in `assets/css/style.css`; the accent colour is the
`--accent` variable.
